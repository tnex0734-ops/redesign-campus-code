# CampusCode Landing Page — Implementation Checklist

This is a working checklist, not a build prompt.

## Before implementation

- [ ] Inspect framework, route and current package versions.
- [ ] Read all design documents.
- [ ] Open both reference images and confirm their visual details.
- [ ] Confirm the real CampusCode logo and font assets.
- [ ] Confirm public event source and existing navigation routes.
- [ ] Confirm whether Lenis is genuinely needed.
- [ ] Write a file-by-file implementation plan.

## Visual construction

- [ ] Warm paper canvas.
- [ ] Low-contrast scientific grid.
- [ ] Original large botanical specimen with layered leaves.
- [ ] Fine vein linework and a few brass details.
- [ ] Strong editorial headline and clear sans body/UI pairing.
- [ ] Five to seven hanging CampusCode artefacts around the hero.
- [ ] Fine suspension cords anchored at the top of each object.
- [ ] No purple gradient, generic SaaS visuals or repeated eyebrow labels.

## Product and conversion

- [ ] First viewport explains CampusCode.
- [ ] Explore hackathons CTA is immediately visible.
- [ ] Join CTA is clear but secondary.
- [ ] Discover → Team up → Build → Ship story is obvious.
- [ ] Events use verified data only.
- [ ] All links use repository-confirmed destinations.
- [ ] No invented stats, testimonials or prizes.

## Motion

- [ ] Hero entrance choreography.
- [ ] Top-pivot hanging swing.
- [ ] Hover/focus/tap response.
- [ ] Every artefact action works.
- [ ] Selected SVG line drawing.
- [ ] Varied organic section reveals.
- [ ] ScrollTrigger cleanup and refresh.
- [ ] One Lenis/GSAP frame loop, if Lenis is used.
- [ ] Pause offscreen / background-tab loops.
- [ ] Reduced motion disables nonessential motion.

## Quality

- [ ] 2048, 1920, 1440, 1280, 1024, 768, 430, 390 and 360px checked.
- [ ] No horizontal overflow.
- [ ] Keyboard and touch paths work.
- [ ] Visible focus states.
- [ ] Correct semantic heading structure.
- [ ] Image dimensions and alt text.
- [ ] Lint, typecheck and production build pass.
- [ ] Browser console and broken links checked.
- [ ] Existing authenticated screens and backend remain unchanged.
